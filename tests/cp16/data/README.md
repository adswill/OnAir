# CP16+ test recordings

`m1_snrp6_M2.wav`, `m2_snrp6_M2.wav` and their `.truth` files (the expected dot matrices, format `GT16`) are unmodified copies from the `samples/` folder of the CP16+ source archive by BD8DQS (https://github.com/hatsunesenya/cp16_plus), MIT licence, full text in `LICENSE-CP16Plus.txt`. They are generated by the CP16+ software at +6 dB, not received off the air. CP16+ is a separate protocol from CRAC's CP16; the tests use only its dot picture (16 carriers, one row per time step).
