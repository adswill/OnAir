What each part rests on:
Carriers 250.450, 250.550 and 250.650 MHz; 16 channel, 75 Bd multiplex; differential BPSK at 1200 Bd; channel 0 for synchronisation; the other channels usually random-looking, encrypted data, sometimes KG-84; no plain text ever seen: the description on r00t.cz (Fleet Broadcast Decoder v0.5, 2009).
16 channels of 75 Bd make 1200 Bd: a frame is 16 bits, one bit per channel. A US Navy FLTSATCOM shore-terminal description also gives 75 bit/s subchannels sent time-division multiplexed at 1200 bit/s.
The software on that page is personal-use, binary only: none of it is used. Everything here is written from the description.
Not published, so not claimed: the sync pattern of channel 0, the pulse shape, the bit polarity, any message framing inside a channel, which satellite uses which carrier. The frame start is found as the one column of the 16-bit frame that repeats (3 to 64 frames) and taken for channel 0: that is an assumption, not a check against the real sync word.
